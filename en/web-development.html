Frequently asked questions

How long does a web development project take?

It depends on scope: a landing page can be ready in days, while an application with an admin panel and user roles takes several weeks. The initial diagnosis defines the real timeline.

Do you work with custom code or builders like Lovable/GoHighLevel?

Both, depending on the project. I prefer custom code (React, Next.js, Node.js) when full control is needed; I use builders when the client already operates on that platform.

Is maintenance included?

Not by default. Delivery includes documentation so the project works independently; ongoing maintenance is quoted as a separate monthly scope if you need it.

Can I see more projects before deciding?

Yes, the full portfolio is filterable by project type: online store, landing/funnel, application, internal system, or automation.
