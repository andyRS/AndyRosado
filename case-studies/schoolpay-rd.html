SchoolPay RD: un producto propio para resolver la gestión de cobros escolares

Nota de transparencia: SchoolPay RD es un producto propio en fase de demo/prototipo, no una plataforma en producción con colegios como clientes pagando hoy. Lo incluyo en el portafolio porque demuestra cómo diseño y estructuro un producto SaaS completo desde cero, incluyendo la interfaz, el flujo de usuario y las credenciales de demostración funcionales.

El problema que ataca

Muchos colegios privados, estancias infantiles y centros de tareas en República Dominicana gestionan mensualidades, morosidad e inscripciones en hojas de cálculo o cuadernos separados, sin visibilidad centralizada ni forma sencilla de dar seguimiento a los pagos atrasados.

La propuesta de producto

Un panel único donde el administrador de un colegio puede controlar mensualidades, morosidad, inscripciones, transporte y comunicados — con notificaciones a los tutores por WhatsApp en vez de depender solo de circulares en papel.

Funcionalidades diseñadas

  • Control de mensualidades y morosidad desde un panel central
  • Gestión de inscripciones y transporte escolar
  • Comunicados a tutores vía WhatsApp
  • Recibos e informes listos para imprimir
  • Acceso administrativo con credenciales de demostración funcionales

Stack técnico

React + Vite + Tailwind CSS 4, con React Router para la navegación. Es una interfaz completamente funcional sobre datos de demostración — el siguiente paso natural de este producto sería conectar un backend real (autenticación persistente, base de datos de pagos, pasarela de cobro) según las necesidades específicas de un colegio real.
