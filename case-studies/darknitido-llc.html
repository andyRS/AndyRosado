DarkNitido LLC: una landing institucional con un formulario de contacto que no confía en nadie

El contexto

DarkNitido LLC es una holding privada — una sociedad matriz que agrupa un portafolio de empresas. Su sitio no necesita vender un producto: necesita comunicar solidez institucional y dar un canal de contacto confiable para las empresas de su portafolio y potenciales socios.

El reto

Un formulario de contacto público es, sin excepción, un blanco de spam y bots automatizados. Para una holding, ese formulario suele ser el único punto de entrada real del sitio — si se llena de spam o es vulnerable, el canal de contacto deja de ser confiable.

La solución

Una landing institucional en Next.js 16 con TypeScript y React 19, donde el formulario de contacto se construyó con seguridad como requisito, no como añadido: honeypot para atrapar bots simples, límite de tasa de solicitudes (rate limiting) para frenar abuso automatizado, y entrega de correo vía Resend para que los mensajes lleguen de forma confiable.

Funcionalidades clave

  • Landing institucional con Next.js 16 y React 19
  • Formulario de contacto con protección honeypot
  • Rate limiting para prevenir abuso del formulario
  • Entrega de correos vía Resend

Stack técnico

Next.js 16 · TypeScript · React 19 · Tailwind CSS 4 · Resend
