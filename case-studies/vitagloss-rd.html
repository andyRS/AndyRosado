VitaGloss RD: e-commerce y gestión de ventas para un negocio de distribución independiente

El contexto

Los distribuidores independientes de Amway en República Dominicana venden productos de cuidado personal y salud, pero suelen operar sin una plataforma propia — dependiendo de catálogos en PDF, WhatsApp y hojas de cálculo para llevar el control de pedidos y clientes.

El reto

Construir una tienda en línea real (no solo un catálogo estático) que además funcionara como sistema de gestión de ventas: que el propio distribuidor pudiera administrar productos, ver pedidos y tener un panel separado del sitio público que ven sus clientes.

La solución

Una plataforma full-stack con frontend en React 19 (Vite, Tailwind CSS, Framer Motion, React Router) y backend en Node.js con Express, Mongoose sobre MongoDB Atlas, y autenticación con JWT y contraseñas cifradas con bcryptjs — la base técnica estándar para un panel administrativo que maneja datos de clientes y ventas de forma segura.

Funcionalidades clave

  • Catálogo de productos con presentación orientada a conversión
  • Sistema de autenticación para el panel administrativo del distribuidor
  • Gestión de ventas separada de la vista pública de la tienda
  • Diseño responsive con animaciones de Framer Motion

Stack técnico

React 19 · Vite · Tailwind CSS · Framer Motion · React Router v7 · Node.js · Express · MongoDB Atlas (Mongoose) · JWT · bcryptjs
