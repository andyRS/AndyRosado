Kingdom Studio: un SaaS que genera y publica contenido editorial con IA

El contexto

Kingdom Studio es un producto propio: una plataforma SaaS que automatiza el ciclo completo de contenido editorial de un ministerio — desde la generación con IA hasta la publicación final — sin que un humano tenga que escribir, formatear y subir cada artículo a mano.

El reto

Automatizar contenido con IA no es solo "generar texto" — es integrar generación, revisión, aprobación y publicación en un flujo que un equipo no técnico pueda operar desde un panel, con control real sobre qué se publica y cuándo. Además, el destino final del contenido (el blog de Restaura Tu Matrimonio, construido en Next.js y desplegado en Vercel) es un entorno serverless: no existe un disco donde simplemente "guardar un archivo nuevo".

La solución

Un panel de control donde el contenido pasa por etapas — generación, revisión, aprobación, programación y publicación — con métricas y analíticas visibles en todo momento. La arquitectura se apoya en FastAPI para el backend, Next.js para el panel, y Supabase como base de datos y autenticación.

El desafío técnico más interesante

Como Vercel no permite escribir archivos directamente en producción, Kingdom Studio no "sube" el contenido al blog — publica a través de un adaptador que abre un Pull Request en GitHub (vía la API de GitHub) contra el repositorio del blog, en una rama nueva, con el artículo en formato MDX y el frontmatter correcto. El CI del blog (lint, type-check, tests y build) corre automáticamente sobre ese PR antes de que un humano lo revise y apruebe — es la primera línea de defensa contra un artículo mal formado. Mientras el PR no se mergea, Kingdom Studio refleja el estado real: DRY_RUN, no PUBLISHED. Es una solución que respeta las restricciones reales de una arquitectura serverless en vez de forzar un atajo.

Funcionalidades clave

  • Generación de contenido asistida por IA (OpenAI/Claude)
  • Flujo de revisión y aprobación antes de publicar
  • Programación de publicaciones
  • Publicación automática vía Pull Requests de GitHub, no escritura directa
  • Dashboard con métricas y analíticas del contenido publicado

Stack técnico

FastAPI · Next.js · Supabase · API de GitHub · Integración con OpenAI/Claude

Estado actual

El producto tiene sus fases fundacionales (estructura, base de datos, panel, sistema de solicitudes) completadas, con el panel administrativo y las integraciones de pago en curso de desarrollo activo. Es un producto propio en evolución, no un proyecto cerrado.
